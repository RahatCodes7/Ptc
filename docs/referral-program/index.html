Referral Links and Rewards

2 min readPenta Core Network

The Referrals section provides your personal link, referral code, activity statistics and reward records. Share the link to invite people to Penta Core.

Standard links#

A standard link looks like https://pentacore.io/?ref=7b737d7d. The ref parameter carries the invitation identifier. Copy your own link from the dashboard; the example above is a format example, not your personal code.

What the screen shows#

Your code and link identify the inviting wallet. The section tracks referred activity, purchases and referral reward records. A link click or wallet connection is not itself a confirmed token purchase. Check the recorded transaction status before interpreting activity as a sale.

Custom names and blogger links#

Custom referral names resolve to the same underlying invitation relationship. The administration can create/manage blogger links and control whether the user-facing Custom referral link field appears. When that field is hidden, ordinary users still have their standard link; they are not being offered a public rename form.

When enabled, a custom name uses 3–32 Latin letters, numbers, hyphens or underscores and must start and end with a letter or number. Names must be available. Saving requires a signature from the connected owning wallet; typing another person's wallet address does not authorize changing their link.

Sharing and attribution#

The interface supports copying the link/code and sharing through Telegram, X, WhatsApp and email. Keep the full ref parameter when sharing. A shortened or branded alias must resolve correctly; removing the identifier breaks the intended referral path.

Rewards are distinct from purchase promos#

Referral records belong to the invitation program. A purchase promo code separately adds PTC to the buyer's quote. Do not promise an automatic buyer discount, a payout for every click or a fixed withdrawal schedule based only on the existence of a referral link. Use the actual reward and status shown for your wallet.
